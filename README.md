
# Astral Rift Alpha 0.8 — Visual Upgrade

Based on the working Alpha 0.7 Dungeon & Boss project.

Adds decorative town lamps, stalls, plaza tiles, player armor details, and dungeon sigils; hides boss HP after victory.

No external models or image dependencies.

## Installation

Replace the existing five project files while preserving the `src/` directory.

Backup Alpha 0.7 before updating.
