# Astral Rift Alpha 0.7 — Dungeon & Boss

Built on Alpha 0.6. Explore the forest gate near x=0, z=-32, press ✦ Судлах (or F) to enter the dungeon. Defeat the Shadow Guardian (650 HP) and earn 250 gold and 220 EXP. Use the glowing exit portal near x=48,z=-36 to return to the forest. Existing controls, inventory, NPC, XP, and exploration remain.

To deploy: replace root index.html, package.json, README.md, and src/main.js, src/style.css.

Note: This is a local procedural Three.js prototype, not an asset-rich commercial game.
