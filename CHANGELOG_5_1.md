# Alpha 5.1 — Rodin Player

- Rodin GLB is loaded as the default playable avatar instead of a floating preview.
- Previous avatar remains available as a fallback via the on-screen toggle.
- Rodin is normalized to 2.35 game units and follows the existing player movement, camera and combat.
- Added lightweight procedural body bob and attack lean.
- Limitation: Rodin GLB has no verified humanoid skeleton; this is **not** full skeletal sword/walk animation.
- Test status: syntax validated; real device/Vercel deployment not yet verified.
